# DNScale CLI 1.0.0

Version 1.0.0 provides zone and record management, read-only DNSSEC/usage,
endpoint-bound authentication, and scriptable JSON output.

- List, inspect, and create zones; list, get, create, update, and delete records.
- Validate record files or stdin locally with `--dry-run` before submission.
- Store named profiles in the OS keychain or use environment credentials in CI.
- Inspect DNSSEC status, public DS records, and account/zone usage.
- Use paginated JSON output, command deadlines, explicit deletion, and shell
  completion on macOS, Linux, and Windows.

## Installation

On macOS or Linux:

```sh
brew install dnscaleou/tap/dnscale
```

Or download your platform's archive and `checksums.txt` from this release.
Archives are available for macOS and Linux on AMD64/ARM64, and Windows on AMD64.
Verify the archive's SHA-256 hash, extract it, and put `dnscale` (or
`dnscale.exe`) on PATH. Prebuilt binaries do not require Go.

With Go 1.25 or newer:

```sh
go install github.com/dnscaleou/dnscale-cli/cmd/dnscale@v1.0.0
```

See the [installation guide](https://github.com/dnscaleou/dnscale-cli/blob/v1.0.0/README.md#install)
and [first DNS workflow](https://github.com/dnscaleou/dnscale-cli/blob/v1.0.0/QUICKSTART.md).
